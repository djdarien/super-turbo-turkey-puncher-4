# Credits

All assets below were created for this project in October 2026 and are original work.
Pixel art drawn procedurally at low resolution with dithering/outlines and upscaled nearest-neighbor via tools/art.py (assets are in public/play/); audio via tools/sfx.py. Generated with Python (Pillow for images, a custom waveform synthesizer for audio, encoded to Ogg Vorbis with ffmpeg).
No third-party art, audio, samples, logos or characters are used. License: same as the project (owned by djdarien).
